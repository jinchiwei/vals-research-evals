# Segmentation feasibility audit, 2026-11-14

The [AWS registry](https://registry.opendata.aws/ucsf-pcnsl/) describes expert-annotated segmentations. The [official tutorial](https://github.com/rauschecker-sugrue-labs/UCSF-PCNSL) describes processed derivatives, rather than distributed raw MRI. These descriptions do not establish independence from any candidate pretrained segmentation model.

The actual archive contains 150 masks for each pattern `sub-XXXX_ses-YYYY_FLAIR_abnormal_seg_comp.nii.gz` and `sub-XXXX_ses-YYYY_T1Post_abnormal_seg_comp.nii.gz`, under `masks/lesions_seg_comp`. The release dictionary identifies integer labels 1–N as distinct lesions in the respective reference image spaces. All 150 patients have T1, T1Post, FLAIR and ADC skull-stripped images registered into each of these two spaces (1,200 images total). No README file exists inside the extracted archive.

The dictionary does not settle whether the two mask families are independent FLAIR-abnormality/enhancing-tumor targets or a shared lesion definition in different reference spaces. That distinction must be established before combining their segmentation scores. The available documentation also does not establish whether any cropping, registration, normalization or other preprocessing used lesion labels. These are unresolved provenance questions, not detected leakage. A segmentation benchmark should isolate reference masks and all mask-derived statistics from the candidate agent, evaluate within the correct image space, and disclose any pretrained-model overlap with this public cohort.

FAC's existing neuronetwork environment provides nibabel and SimpleITK; PyRadiomics and nnUNetv2 are not installed there. The released feature tables can therefore be evaluated immediately, but recomputing radiomics from predicted masks or running pretrained nnU-Net requires an additional environment/model setup. No segmentation inference, model installation or new preprocessing was performed in this audit.

A full read-only header check compared each of the 300 masks with all four images in its reference space: **1,200 pairs across 150 patients, zero shape mismatches, zero affine mismatches** (rtol 1e-5, atol 1e-4), and no nonfinite affines or missing sequence sets. Voxel arrays were not read. This establishes matching grids, not annotation validity or target equivalence. The aggregate machine-readable audit is `pcnsl/results/20261114-prediction-data/segmentation-audit.aggregate.json`.
